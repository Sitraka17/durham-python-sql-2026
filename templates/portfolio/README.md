# Starter portfolio site — launch in ~5 minutes

This folder is a ready-to-use GitHub Pages homepage. Copy it, change a few
words, and you have a live personal site at `https://YOUR-USERNAME.github.io`.

## Steps

1. On GitHub, **create a new repository named exactly `YOUR-USERNAME.github.io`**
   (all lowercase, your real username). Make it **public**.
2. Upload the two files from this folder into that new repo:
   - `index.md`
   - `_config.yml`
   *(On github.com: "Add file" → "Upload files", or use git.)*
3. Open `index.md` and `_config.yml` and **replace every placeholder**:
   `YOUR NAME`, `YOUR-USERNAME`, `your.email@...`, `YOUR-PROFILE`, `YEAR`, etc.
4. In the new repo: **Settings → Pages → Build and deployment →
   Source: "Deploy from a branch" → Branch: `main` / `/ (root)` → Save.**
5. Wait ~1 minute, then visit **`https://YOUR-USERNAME.github.io`**. 🎉

## Make it yours

- Add a project each time you finish one — lead with the *finding*.
- Embed one chart per project so the result is visible at a glance.
- Link the site from your CV, LinkedIn and email signature.
- Want a richer look? Swap the theme in `_config.yml` for any
  [supported GitHub Pages theme](https://pages.github.com/themes/), or use a
  template like [academicpages](https://academicpages.github.io).
